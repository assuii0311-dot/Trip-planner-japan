# 일본 — 음식·쇼핑·n차, 그리고 재방문자

도쿄를 열고 실제로 눌러 본 뒤 나온 세 가지 지적을 다룬다.

1. 1단계 지역 구분이 여행자의 기준과 다르고, 초심자용뿐이다. 일본은 여러 번 간다.
2. 2단계가 스페인 기준이다(타파스·유로·와이너리).
3. 일본 여행의 특색은 음식과 쇼핑이다. 저녁은 가게 하나가 아니라 n차다.

---

## 1. 지역 구분 — 무엇을 기준으로 나눴나

Wikivoyage 는 도쿄를 구(區) 단위 문서로 나눈다(Chiyoda, Taito, Minato …).
행정 구역은 여행 단위가 아니다. 다이토구에는 우에노와 아사쿠사가 함께
있지만 여행자는 둘을 따로 부르고, 미나토구의 롯폰기와 오다이바는 지하철로
30분이다.

그래서 **역을 중심으로 걸어서 도는 생활권**으로 다시 묶었다. 문서 둘을
합치거나(긴자+쓰키지, 시부야+하라주쿠, 롯폰기+도쿄타워), 한 문서를 반경으로
잘랐다(세타가야 문서에서 시모키타자와만). 기준은 세 가지다.

- 한 역에서 내려 걸어서 도는 범위인가(반경 1~2km)
- 여행자가 그 이름으로 부르는가(아사쿠사, 긴자 — 다이토, 주오가 아니라)
- 반나절 볼거리가 있는가

지역의 중심 좌표에서 반경의 두 배 밖에 있는 리스팅은 뺀다(`collect.mjs`).
좌표가 없는 것은 남기고, 먼 것은 손으로 뺀다(`japan-extras.mjs` DROP).

### 재방문자

지금까지의 지역은 도쿄가 처음인 사람의 목록이었다. 일본은 두 번, 세 번
간다. 두 번째부터는 센소지가 아니라 동네를 간다.

- **시모키타자와** — 빈티지 옷가게와 작은 극장, 카레 골목
- **나카메구로·다이칸야마** — 메구로강 벚꽃길, 편집숍, 다이칸야마 T-SITE

성격 프로필에 `firstTimer: false` 를 두고 `재방문` 태그를 붙였다. 1단계의
'처음이라면 이곳부터' 를 켜면 숨고, 끄면 보인다. 다음 후보는 고엔지·
구라마에·기요스미시라카와·가구라자카다. Wikivoyage 에 독립 문서가 없어
손으로 넣어야 한다(아래 출처 절).

### 출처 — 재방문자용 목록을 어디서 얻나

| 출처 | 재방문자에게 | 저장 | 판단 |
|---|---|---|---|
| Wikivoyage | 대표 명소 위주. 동네 문서는 얇다 | 가능 | 뼈대로만 |
| Wikidata | 좌표·언어판 수. 언어판이 적은 곳이 곧 숨은 곳 | 가능 | `discovery` 축의 재료. 이미 쓴다 |
| Wikipedia(일본어) | 상점가·동네 문서가 풍부(下北沢, 谷中銀座) | 가능(CC BY-SA) | 동네 소개와 좌표를 받는 후보 |
| OpenStreetMap | 카페·빈티지숍·라이브하우스가 촘촘 | 가능(ODbL) | 동네 안 가게를 세는 데는 쓸 만하다. 설명은 없다 |
| 타베로그·구글 | 평점·후기 | 불가 | 런타임 링크로만(이미 한다) |
| 여행 블로그·유튜브 | N회차 취향 그 자체 | 불가 | 사람이 읽고 손으로 옮긴다 |

결론: **뼈대는 Wikivoyage+Wikidata, 재방문 동네의 살은 사람이 넣는다.**
스페인 섬(`island-extras.mjs`)과 같은 방식이고, 도쿄도 이미 50곳을 그렇게
넣었다. 자동으로 긁어 올 수 있는 출처 중 저장이 허용된 것은 설명이 없고,
설명이 있는 출처는 저장이 안 된다.

## 2. 2단계 — 나라별로

음식·쇼핑 선택지와 문구를 나라별로 뺐다(`Step2Preferences.tsx`).

| | 스페인 | 일본 |
|---|---|---|
| 음식 | 현지 가정식·타파스·파인다이닝·시장·해산물·채식·카페·와인 | 스시·해산물 / 라멘·소바·우동 / 이자카야·꼬치 / 돈카츠·야키니쿠·정식 / 가이세키·오마카세 / 시장·요코초·데파치카 / 카페·디저트·말차 / 사케·위스키·크래프트 비어 / 노포 / 채식 |
| 쇼핑 | 묻지 않는다 | 백화점·복합몰 / 드럭스토어·돈키호테·100엔 / 애니·피규어·게임·전자 / 편집숍·빈티지·패션 / 공예·문구·주방도구 / 상점가·시장 골목 |
| 예산 | €15 / €40 | ¥2,500 / ¥6,500 |
| 밤 | 가볍게 한잔 / 적극적으로 / 밤이 본편 | 저녁만 / 2차까지 / 3차까지 |

선택지의 값(value)은 아이템 `tags` 와 맞추는 열쇠다. 파이프라인이 리스팅
본문에서 태그를 뽑는다(`enrich.mjs` — sushi·noodle·izakaya·comfort·bar·
department·variety·otaku·select·craft·street). 손으로 넣은 항목에도 같은
태그를 붙였다.

## 3. 음식·쇼핑을 어떻게 강화했나

### 점수

고른 음식 취향과 태그가 겹치면 아이템 점수에 +9씩 붙는다(이미 있던 규칙).
**쇼핑에도 같은 규칙을 넣었다**(`scoring.ts`). 백화점을 고른 사람에게
피규어 가게가 앞에 오지 않는다.

### 코스

일본 지역의 성격 프로필은 미식·쇼핑이 3인 곳이 많다(긴자, 신주쿠, 아키하바라).
1단계에서 지역을 고르면 그 취향이 역산되어 2단계 기본값이 되고, 3단계
코스 순위가 그쪽으로 기운다(±25%). 미식은 코스에 넣지 않고 '미식 후보'
로 따로 보여 준다는 원칙은 그대로다 — 식사는 어차피 하므로 여행이
길어지면 안 된다.

### 저녁은 n차다

스페인은 저녁 뒤 밤 자리가 하나다(바 또는 플라멩코). 일본의 저녁은
이자카야에서 먹고 → 바로 옮겨 한 잔 → 라멘으로 끝내는 n차가 보통이다.

- 나라 데이터에 `nightRounds: 2`(일본). 스페인은 1.
- 밤 취향이 '3차까지(밤이 본편)' 이면 마지막 밤 자리 뒤에 90분 간격으로
  한 자리를 더 둔다(`planner.ts` `withNightRounds`).
- **3차는 2차와 다른 종류로, 그리고 가까운 곳으로.** 앞 자리가 있으면
  `bar` 태그(사케·위스키·크래프트 비어)나 온천에 1.3배, 그 밖에는 0.8배를
  주고 앞 자리에서의 거리로 다시 가중한다(`nthRound`).
- 화면은 저녁 식사를 1차로 보고 밤 자리를 '밤 · 2차', '밤 · 3차' 로
  부른다(`slotLabelOf`). 밤이 하나뿐인 날(스페인)은 그냥 '밤' 이다.

주류 페어링 자체(이 안주에 이 술)는 데이터에 없다. 술집의 종류(izakaya /
bar)와 위치로 n차의 모양만 만든다. 페어링까지 가려면 아이템에 '무엇을
마시는 곳인가' 를 사람이 적어야 한다 — 오모이데요코초(맥주·꼬치),
골든가이(위스키·칵테일)처럼 이미 설명에는 적혀 있다.

## 4. 남은 것 — 순서대로

1. **실제 사용 확인** — 2단계에서 '이자카야·꼬치'+'사케·위스키' 를 고르고
   밤을 '3차까지' 로 두면 4단계 저녁이 이자카야 → 바 → 라멘으로 이어지는지.
2. **재방문 동네 추가** — 고엔지·구라마에·기요스미시라카와·가구라자카.
   Wikivoyage 문서가 없어 `japan-extras.mjs` 에 손으로 넣는다(동네당 8~12곳).
3. **음식 태그의 정밀도** — `comfort` 가 넓다(돈카츠부터 카레까지). 실제로
   써 보고 갈라야 하면 가른다.
4. **1회차/N회차 물음** — 지금은 1단계의 '처음이라면 이곳부터' 토글이 그
   역할이다. 2단계에서 "일본이 몇 번째인가" 를 묻고 `discovery` 기본값과
   지역 목록을 함께 바꾸는 편이 자연스럽다. 화면 1~3단계를 건드리는
   일이라 따로 정한다.
